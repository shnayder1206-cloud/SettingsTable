# BokSort — сортировщик и валидатор боковины (.bok)

Консольное приложение .NET (net8.0). Грамматика и правила проверки — в `bok.rules`.

## Требования
- .NET SDK 6+ (проект собран и проверен на .NET 8)

## Структура
```
├── BokSort.csproj        # файл проекта
├── BokSort.cs            # исходник
├── bok.rules             # спецификация формата .bok
└── data_for_test/        # тестовые файлы боковин
```

## Сборка и запуск
```bash
dotnet build
dotnet run -- data_for_test/bokrai_bs5.txt sorted_bokrai_bs5.txt
dotnet run -- --fix input.bok output.bok   # режим нормализации
```
Аргументы: `<вход> [выход]`; без выходного файла создаётся `sorted_<вход>` в текущей директории.

## Кодировки
Входные файлы читаются как UTF-8; если это не удаётся — автоматически используется
Windows-1251 (тестовые файлы в `data_for_test/` именно в этой кодировке).
Выходной файл пишется в той же кодировке, что и входной.
